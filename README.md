# わたし推し活 毎日のお題(5期)

推し活サイト(`jibun-mitashi-card`)から独立させた、12/3〜1/6の35日間・5週の「毎日のお題」アプリ。2026-11-25 に、推し活サイトに足す形から別アプリに変更(かすみんの決定)。

- 使えるのは、名簿(`roster` シート)で期が「5期」か「運営」の人だけ(`Code.gs` と `app.js` の `ODAI_GROUPS`)。それ以外の人は「このアプリは、5期のみなさん向けです。」だけが出る。サーバー側でも記録・ノートを `odai_5ki_only` で断る
- ログインは、SkipFマイページの「呼び名」を入れるだけ(推し活サイトと同じ)
- 12/2までに開くと「12/3(木)に、オープンします。」の画面。期間は `app.js` / `Code.gs` の `PROGRAM_START_DATE`(2026-12-03)・`PROGRAM_LENGTH`(35)と、`odai.js` / `Code.gs` の `ODAI_START_DATE` / `ODAI_LENGTH` で、すべて同じ期間にしておく
- 画面: ホーム(WEEK・今週のテーマ・4つのメニュー)→ 今日のお題(ヒント・記入例を見る)→ 入力(500文字)・五感タップ(任意)・写真 → 取り組みカレンダー(🌸アプリの記録 / 📖手書きノートのスタンプ、今週の取り組み)→ わたしの記録 → テーマ一覧 → 使い方。タブは「わたしの記録 / みんなの投稿 / 管理者」
- お題の中身は `odai.js`(元は依頼者さんのスプレッドシート「アプリのお題」)。文章を直すときは `odai.js` を直して push するだけ
- 手書きノートのスタンプは `students` シートの `note_dates` 列
- みんなの投稿・コメント・リアクション・運営・管理者タブ・写真のしくみは推し活サイトと同じ。写真の保存先はGoogleドライブの「毎日のお題写真」フォルダ
- 端末に覚えるキーは `odai_` で始まる(推し活サイトの `jmc_` とは別)

## 技術構成

ビルド不要の静的サイト(HTML / CSS / 素のJavaScript)を GitHub Pages で公開。データは Google Apps Script 経由で、推し活サイトとは**別の**Googleスプレッドシートに保存(`students`・`records`・`comments`・`roster` のシートは自動で作られる)。管理者の合言葉はスクリプトプロパティ `ADMIN_PIN`(GitHubには載らない)。

## セットアップ

1. 新しいGoogleスプレッドシートを作る(名前の例: 「わたし推し活 毎日のお題 DB」)
2. 「拡張機能」→「Apps Script」で、中身を全部消して [`apps-script/Code.gs`](apps-script/Code.gs) を貼り付けて保存
3. 「プロジェクトの設定」→「スクリプト プロパティ」に `ADMIN_PIN`(管理者の合言葉)を追加
4. 関数 `authorizeDrive` を1回「実行」して、ドライブへのアクセスを許可(写真用)
5. 「デプロイ」→「新しいデプロイ」→ ウェブアプリ(次のユーザーとして実行: 自分 / アクセスできるユーザー: 全員)→ `.../exec` のURLを [`config.js`](config.js) の `PRODUCTION_URL` に入れる
6. 管理者タブ →「期(グループ)の設定」で、5期と運営の呼び名を登録する
7. GitHub に Public のリポジトリ `oshikatsu-odai` を作って push し、`Settings` → `Pages` → `main` / `(root)` で公開

Code.gs を直したときは「デプロイを管理」→ 鉛筆 →「新バージョン」(「新しいデプロイ」はURLが変わるので使わない)。style.css / app.js を直したときは、`index.html` の `?v=` の数字を1つ増やす。

## 手元での確認

`.claude/launch.json` の「oshikatsu-odai」(ポート8097)。`Code.gs` をそのまま疑似スプレッドシートで動かす。画面の日付は `?today=2026-12-10`、サーバー側の日付は `/__set?today=2026-12-10`(2つをそろえる)。`/__reset` でデータを初期化。

## デモ環境

まだ作っていない。作るときは、デモ用スプレッドシートの Apps Script のURLを `config.js` の `DEMO_URL` に入れ、`TEST_TODAY` を `demoToday` と同じ日付にする。`DEMO_URL` が空のあいだは、`?demo=1` を付けても本番につながる。

## 配るURL

LINEで配るときは、末尾に `?openExternalBrowser=1` を付ける。
